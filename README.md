# 天気痛予報・管理アプリ

気圧変動による体調不良（天気痛）に悩む方に向けた、パーソナライズ天気痛予報および体調記録・管理システムです。

---

## 開発の背景・目的

天候の変化によって頭痛や倦怠感などの体調不良を起こす「天気痛」の認知が進んでおり、悩んでいる方が増えています。
私自身も天候によって体調が左右されますが、既存のアプリでは一定の気圧変動にのみフォーカスしているものが多いと感じており、気圧のほかにの温度・湿度変化に対応したアプリがあればと思い、現在作成しております。
本アプリは以下の2点を主な目的として開発しています。

---

## 主な機能（予定含む）

- [ ] **ユーザー管理機能**（新規登録・ログイン・プロフィール設定）
- [ ] **パーソナライズ天気痛予報表示**（気圧データと個人傾向を元にした予報）
- [ ] **天気痛・体調記録機能**（日付、時間帯、症状の強さ、メモ等の登録）
- [ ] **ユーザー別閾値の自動カスタマイズ機能**（記録をもとに、天気痛予測の閾値を下げる）
- [ ] **記録データの可視化**（過去１年分の履歴一覧表示）
- [ ] **医師提示用データ出力・表示**（診断時に活用しやすいフォーマットでの出力）

> ※現在制作中のため、機能は順次実装・更新中でございます。

## 使用技術（Tech Stack）

- **フロントエンド / 画面描画:** JSP (JavaServer Pages), HTML5, CSS3, JavaScript
- **バックエンド:** Java (Servlet / MVCモデル 他)
- **データベース:** RDBMS (MySQL)
- **バージョン管理:** Git / GitHub

---

## データベース設計（テーブル概要）

- **users（ユーザー）：アカウント情報を保持する。
- **pain_records（症状履歴）：記録された天気痛記録の過去1年分の履歴を保持する。
- **symptom（症状マスター）：代表的な天気痛の症状を保持する。
- **uuser_thresholds（ユーザー別閾値）：ユーザー別の閾値を管理する。
- **uweather_triggers（閾値計算用）：ユーザー別の閾値を算出するため、症状が登録された直近3回までの気圧・気温・湿度変化の閾値を保持し、ユーザー別閾値に反映する。
- **uweather_snapshots（記録時の天気情報）：記録時の天候・気圧・気圧・気温・湿度と、そこから24時間の間での気圧・気温・湿度変化の最大値を保持する
